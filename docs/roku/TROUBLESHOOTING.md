# Troubleshooting

## Debug console workflow

```bash
telnet <ROKU_IP> 8085     # BrightScript console: prints and crash traces
telnet <ROKU_IP> 8080     # graphics console: r2d2_bitmaps / r2d2_frames
```

Every `LogInfo()` line is prefixed `[Spotlight]`.  Verbose `LogDebug()` lines
only appear on **sideloaded developer builds** (`roAppInfo.IsDev()`), so a
published channel's console stays clean during certification.

First useful lines after a launch:

```
[Spotlight] Catalog loaded: 7475 wallpapers (… ms read, … ms total)
[Spotlight] Daily Spotlight computed in … ms: <title>        (or "served from cache")
[Spotlight] First frame rendered in … ms
```

## Symptom → cause

| Symptom | Likely cause / fix |
|---|---|
| Channel shows the splash and returns to the home screen | A runtime error before the first frame. Read 8085. Check the catalog is present (`assets/catalog.json`) and the images exist |
| Every card shows a spinner forever | No CDN reachability, or the catalog's `filename`s don't match `images/…`. Check `LogDebug` lines like `HTTP 404 for …` |
| 4K wallpapers show the thumbnail in the viewer | Expected only if the texture manager is unavailable; otherwise check `HandleTextureEvent` state codes (4 = failed, 5 = cancelled) in the console |
| The grid's second row looks cut off | It isn't: the footer starts at y=970 and the grid ends at 958. If it looks wrong, you are on an older package — the previous layout overlapped by 40 px |
| A key press does nothing | Check you are not on a release event (code ≥ 100) — those are ignored by design |
| Store prices show `$4.99`-style placeholders | `GetCatalog()` has not answered yet, or the products don't exist in the Developer Dashboard. Create them, then re-enter the store |
| "Roku Pay is unavailable" | `roChannelStore` could not be created (rare) or the account/region cannot purchase. Free mode still works |
| Splash looks letterboxed or stretched | The manifest declares `ui_resolutions=fhd,hd`; both splash sizes must exist and match 1920×1080 / 1280×720 (`make roku-check`) |
| Deep link does nothing while running | `supports_input_launch=1` must be in the manifest; re-sideload after editing it |
| Back exits from inside a screen | It shouldn't: Back returns grid→tab bar→exit, and viewer/ambient/dialogs return to their origin. A build that exits everywhere predates this fix |

## Local verification without a device

```bash
make roku-audit     # state keys, Roku API surface, dead calls, manifest invariants
make roku-lint      # BrighterScript compile gate (both packages)
make roku-check     # audit + size / artwork / entry points / deprecated APIs / catalog
make test           # Python + JS unit tests for the rest of the repo
```

The compile gate catches the whole class of "undefined name" and type-signature
bugs — including the missing animation clock that used to kill the channel on
its very first frame.  The audit catches the class the compiler cannot see:
keys read but never assigned, and calls to methods Roku components do not
implement (`roBitmap.DrawResizedObject()`, `roFont.SetSize()`) — see
[AUDIT.md](AUDIT.md).  The daily-pick hash has six parity vectors
(`RunDailyHashSelfTest()`) generated by `src/utils.py::daily_score`, so the TV
cannot silently disagree with the web client.
